# SEO Audit & Metadata Architecture

This document audits the template's current Search Engine Optimization (SEO) status and outlines the technical specifications for implementing metadata, OpenGraph tags, robots configs, and dynamic sitemaps for SA Enterprises.

---

## 1. Current SEO Audit

A codebase audit reveals that SEO features are almost entirely unconfigured:

*   **Global Metadata**: The title and description are left as Next.js template defaults inside [app/layout.js](file:///c:/Users/Eldo/Downloads/Projects/SA%20Enterprises/envolve/app/layout.js#L41-L44):
    ```javascript
    export const metadata = {
        title: 'Create Next App',
        description: 'Generated by create next app',
    }
    ```
*   **Page-Specific Metadata**: **Missing**. No individual page route (e.g. `about-1/page.js`, `shop/page.js`) contains any metadata declarations.
*   **Semantic Heading Structure**: Inconsistent. Many pages lack a structured heading hierarchy. For example, some pages skip `<h1>` entirely and start layout sections with nested `<h2>` and `<h3>` tags used purely for CSS font-sizing purposes.
*   **Image Alt Attributes**: Nearly all `<img>` tags in the layout files use empty alt fields: `alt=""`. This hurts image-search rankings and fails standard accessibility guidelines.
*   **Robots & Sitemap**: **Missing**. The `public/` directory contains no `robots.txt` or `sitemap.xml`, and the project has no Next.js config files to generate them.
*   **Canonical Links / OpenGraph / Twitter Cards**: **Missing** entirely.

## 2. SEO Implementation Plan for SA Enterprises

To prepare the site for production under SA Enterprises, the following architecture must be implemented:

### Step 1: Establish Global Metadata Defaults
Update the main metadata object inside [app/layout.js](file:///c:/Users/Eldo/Downloads/Projects/SA%20Enterprises/envolve/app/layout.js#L41-L44) with default brand tags:
```javascript
export const metadata = {
    metadataBase: new URL('https://saenterprises.com'),
    title: {
        default: 'SA Enterprises | B2B Procurement & Business Solutions',
        template: '%s | SA Enterprises'
    },
    description: 'SA Enterprises helps companies source and procure IT hardware, enterprise laptops, network installations, office technology, consumables, and custom equipment. Where Business Needs Come First.',
    keywords: ['B2B Sourcing', 'IT Procurement', 'Office Supply Sourcing', 'Enterprise Hardware Sourcing', 'Consumables Sourcing'],
    openGraph: {
        title: 'SA Enterprises | B2B Procurement & Business Solutions',
        description: 'Corporate hardware procurement, network equipment, and office consumables sourcing. Where Business Needs Come First.',
        url: 'https://saenterprises.com',
        siteName: 'SA Enterprises',
        locale: 'en_US',
        type: 'website',
    },
    twitter: {
        card: 'summary_large_image',
        title: 'SA Enterprises | B2B Procurement & Business Solutions',
        description: 'Where Business Needs Come First.',
    }
}
```

### Step 2: Define Page-Specific Metadata
Export specific `metadata` objects in the individual page routes. For example:

*   **Products Page (`app/products/page.js`)**:
    ```javascript
    export const metadata = {
        title: 'Product Sourcing Catalogue',
        description: 'Browse SA Enterprises catalogue of business tech accessories, laptops, monitors, toner, cables, and custom procurement services.',
    }
    ```
*   **About Page (`app/about/page.js`)**:
    ```javascript
    export const metadata = {
        title: 'About Us',
        description: 'Learn about SA Enterprises, our B2B procurement network, and how we coordinate sourcing and delivery to keep corporate operations running smoothly.',
    }
    ```

### Step 3: Configure Dynamic robots.js & sitemap.js
Rather than manual text files, leverage Next.js App Router files to generate SEO paths dynamically:

1.  **Robots Config [NEW] (`app/robots.js`)**:
    ```javascript
    export default function robots() {
        return {
            rules: {
                userAgent: '*',
                allow: '/',
                disallow: '/private/',
            },
            sitemap: 'https://saenterprises.com/sitemap.xml',
        }
    }
    ```
2.  **Sitemap Config [NEW] (`app/sitemap.js`)**:
    ```javascript
    export default async function sitemap() {
        const baseUrl = 'https://saenterprises.com'
        
        const routes = ['', '/about', '/solutions', '/products', '/faq', '/contact'].map((route) => ({
            url: `${baseUrl}${route}`,
            lastModified: new Date().toISOString().split('T')[0],
            changeFrequency: 'weekly',
            priority: route === '' ? 1.0 : 0.8,
        }))

        return routes
    }
    ```

### Step 4: Semantic Content Corrections
1.  **Audit Heading Nesting**: Ensure each page contains exactly one `<h1>` (typically in the Page Title Banner or Hero title) and nest sections using logical sequential headings (`<h2>`, then `<h3>`).
2.  **Add Alt Content**: Replace all empty `alt=""` attributes in active images with concise text (e.g. `alt="Business laptop mockup sourcing - SA Enterprises"`).
